# dependencys
A List of Projects that i would like to improve with awesome-os

## Quick Start (Windows / Linux / macOS)

```sh
# Clone & enter repository (all platforms)
git clone https://github.com/awesome-os/dependencys.git && cd dependencys
```

## Quick Install & Run (Windows / Linux / macOS)

```sh
# Install / hydrate from v11 CAS via holo-pm
holo-pm install repository://github.com/awesome-os/dependencys@main

# Or project & run directly via holo-project (0-byte hardlink)
holo-project "project://cpp/dependencys?from=repository://github.com/awesome-os/dependencys@main"
```
